# Manifest Schema

Required fields: `id`, `name`, `version`, `category`, `subtype`, `intents`, `keywords`, `paperStyles`, `aspectRatios`, `slots`, `duration`, `motionEnergy`, `compatibleMotions`, `soundTags`, `themeTokens`, `accessibilityLabel`.

IDs use lowercase dot notation: `foundation.surface.smooth-editorial`.
Versioning follows semantic versioning. Breaking configuration changes increment the major version.
