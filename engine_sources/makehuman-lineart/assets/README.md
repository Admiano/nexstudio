# NexStudio MakeHuman asset library

The modular asset library the presenters pipeline (`engine_sources/makehuman-lineart`) loads via `MH_ROOT`. Point `MH_ROOT` at a checkout of this branch.

## Layout
- `makehuman_system_assets_cc0/` — MakeHuman system assets (CC0)
- `proxymeshes/`, `skins/`, `eyes/`, `eyebrows/`, `eyelashes/`, `teeth/`, `tongue/` — base body components
- `hair/`, `hair01_cc0/`, `hair02_ccby/` — hair packs
- `clothes/`, `dress03_cc-by/`, `shirts01_cc0/`, `shirts02_ccby/`, `pants01_cc0/`, `pants02_ccby/`, `shoes02_ccby/` — garment packs
- `packs/` — bundled packs

License folders carry their own terms (cc0 / cc-by). CC-BY content requires attribution.
