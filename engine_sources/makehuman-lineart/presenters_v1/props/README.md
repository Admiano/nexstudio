# Props

`modern_arm_chair_01.blend` — Poly Haven `modern_arm_chair_01` (CC0), 1k glTF
imported and repacked. `modern_arm_chair_01.seat.json` is its seat descriptor
measured by `scripts/cast_chair.py` (seat top 0.45m after the recorded scale,
facing -Y). `scripts/cast-seat-scene.py` consumes the pair to seat a baked
timeline under a real chair for seated/podcast shots.
