# Native performance rollback

The V19 native performance integration is withdrawn at the user's request. The original illustrated native V18 rig and face actions, including their complete 998-frame timeline and gesture variants, are restored to the working front and fixed left three-quarter character scenes. Character geometry, shape geometry, UVs and materials match the pre-rollback current visuals.

The assembled renderer is restored byte-for-byte to its pre-V19 version. The V19 exporter, director, adapter and runtime hook are removed from this branch, preventing them from replacing the original actions again. The prior work remains in Git history for reference only. No production deployment is claimed.

Native preview images are rendered from the restored saved actions at their original frame times. The diagnostic scene has no new narration; no audio is added or retimed. Current illustrated appearance and centered watch geometry are preserved. The V19 conversation and old V19 clips are historical review artifacts, not the active performance authority.
