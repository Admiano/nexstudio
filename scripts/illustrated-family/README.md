## Rebuild a candidate

Requires Python 3.10+, original repository checkout, Linux `zstd`, and **Blender 5.2.0**.

```bash
python scripts/illustrated-family/build_formal_cast.py --list

python scripts/illustrated-family/build_formal_cast.py \
    --variant female-double-breasted \
    --blender /absolute/path/to/blender-5.2.0-linux-x64/blender \
    --output-dir /absolute/path/to/proof
```

It downloads or reuses the original upstream CC0 assets from MakeHuman Community, validates their hard-coded SHA-256 checksums, opens a **disposable** decompressed copy of the canonical source scene, transfers garment and shoe skinning to `Host.rig`, restores real UV material textures and runs the original action at 338/891.

The builder writes front/three-quarter/gesture PNGs, an editable fitted `.blend`, an image render log and a source/asset provenance JSON. Every variant is **unapproved** until visually checked. Original source files, original actions, current NexStudio caster and existing UI presets remain unchanged.

## Production release gates

**Do not present these as already available in the character creator.** The experiments are self-contained and a `CastSpec.outfit` or Cast API connection has not been enabled. Before release, visually inspect at least 10 original action frames, run collision/clip checks on cuffs, knees and shoes, bake/export the garments into the existing asset/GLB pipeline, verify license metadata and certify a two-actor podcast scene.
